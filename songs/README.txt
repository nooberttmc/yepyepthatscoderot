Drop your own tracks here (WAV, AIFF or AU) and press F5 in song select.

  * Name files "Artist - Title.wav" to fill in the metadata.
  * Charts for all four difficulties are generated automatically (tempo, beat
    phase and onsets are detected from the audio).
  * MP3/OGG/FLAC aren't supported by Java Sound; convert first, e.g.
        ffmpeg -i "Artist - Title.mp3" "Artist - Title.wav"
  * Only add music you have the right to use. "No copyright" uploads are not
    always free to use, so check the artist's own licence terms.
